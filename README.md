Плагин для Matrix Synapse: при получении текстового сообщения для заданного
пользователя преобразует сообщение в QR-код и отправляет на печать.

Python 3.14
matrix-synapse (в то же окружение)
UPS (Linux)

Разбиение длинного сообщения на отдельные QR не предусмотренно. Библиотека qrcode имеет предел емкости по символам 2330 латиницей или 1150 кириллицей.
Зашифрованные комнаты не поддерживаются.

upd: на стандартном принтере печатается дополнительные данные, а также вносятся в БД  sqllite
